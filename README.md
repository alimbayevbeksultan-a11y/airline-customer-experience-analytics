Airline Customer Experience Analytics

This project is about analyzing airline passenger satisfaction using SQL and Power BI.

I used a dataset with 129,880 passenger records and looked at how satisfaction changes depending on travel type, class, service quality and flight delays.

## Tools

- SQL
- SQLite
- Power BI
- DAX
- Excel

## What I did

- Cleaned and prepared the data
- Analyzed the dataset using SQL
- Calculated satisfaction rates
- Compared satisfaction between Business and Personal travel
- Compared satisfaction across different travel classes
- Analyzed service ratings
- Compared departure and arrival delays between satisfied and dissatisfied passengers
- Built a Power BI dashboard

## Main results

- 43.45% of passengers were satisfied
- Business travelers had a much higher satisfaction rate than Personal travelers
- Business Class had the highest satisfaction rate
- Seat Comfort had one of the biggest differences between satisfied and dissatisfied passengers
- Dissatisfied passengers had higher average departure and arrival delays

## Dashboard

The Power BI dashboard contains two pages.

The first page shows overall passenger satisfaction, satisfaction by travel type and satisfaction by class.

The second page focuses on service ratings and flight delays.
